只檢查六件事

基本檢討的範圍，先說清楚

這份報告僅依甲方提交且可辨識的乙方報價單與施工圖版本進行書面整理。 正式服務會對文件核對、差異標示、來源引用與留痕負責； 超出下列範圍的判斷不會寫入報告。

  1. 01
    文件完整性

    確認乙方報價單與施工圖是否都已收到、可開啟並可辨識。

  2. 02
    文件版本

    列出目前採用的文件名稱與版次，保留後續版本差異的核對基準。

  3. 03
    報價範圍差異

    指出報價項目之間的包含、未列與說明差異，不替任何一方改寫價格。

  4. 04
    施工圖對照

    將報價描述對照施工圖標示，找出名稱、範圍或數量需要確認之處。

  5. 05
    待補件

    列出目前無法核對的原因，以及需要哪一方補上哪一份資料。

  6. 06
    下一步

    清楚標示下一位處理者與要完成的動作，避免文件停在無人處理的狀態。

引用同一份事實

每一項意見都要帶著來源

報告意見必須同時帶有文件名稱與版次。甲方之後看到新版本時， 仍能回頭確認這一項意見原本依據的是哪份文件；新版本不會覆寫舊版本。
