先了解服務

服務說明

萊比圖說檢討會把「圖面現在能支持的討論」與「仍需報價、細部圖或乙方說明的決策問題」分開，讓甲方知道下一個問題要交給誰。

01圖說是否有明確檔名、版次與提供者。

02圖號、頁面範圍與空間名稱是否足以辨識。

03尺寸、文字與細部索引是否清楚到可討論。

04哪些問題仍需報價或乙方補充才能判斷。
